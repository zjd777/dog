串联四足狗——机械结构与关节角度约定
整理日期：2026-11-05
用途：独立记录本次对话中用户提供的机械关系和最终采用的角度定义，供后续代码适配使用。
说明：已确认的结构、约定的数学定义、暂定软件范围和待实机标定事项分别列出，不混为一谈。

============================================================
一、整体结构
============================================================

1. 机器人为四足机器人，每条腿两个主动自由度：髋关节、膝关节。
2. 整机计划使用八台宇树 GO-M8010-6／8010 电机。
3. 单腿是串联两连杆结构：机身 -> 髋关节 -> 大腿 -> 膝关节 -> 小腿 -> 足端。
4. 膝关节通过同步带远程驱动，因此两个电机都可以布置在髋部。
5. 两个电机位于髋部，不代表它是并联机构。
6. 参考 Corgi 原工程是并联五连杆腿。其闭链正逆解、雅可比不能直接用于本串联腿。
7. 当前电机还未实装，没有可用于安装标定的机器人实物，电机 ID 与实际关节位置尚未分配。

============================================================
二、用户已经确认的驱动和连接关系
============================================================

髋关节：
- 髋电机外壳固定在机身上。
- 髋电机减速器输出端直接连接大腿，驱动大腿相对机身转动。

膝关节：
- 膝电机外壳随大腿一起转动。
- 膝电机通过同步带驱动膝部带轮。
- 下带轮与小腿刚性连接。
- 上、下同步带轮均为 28 齿，机械传动比为 1:1。
- 此前截图显示同步带为非交叉布置。

这些结构决定：
- 髋电机输出角与大腿相对机身的角度，通过参考角和方向标定对应。
- 膝电机输出角与小腿相对大腿的角度，通过参考角和方向标定对应。
- 计算相对膝角时，不额外减去髋角，因为膝电机外壳本身已经跟随大腿运动。

============================================================
四、坐标系和髋关节角 q1
============================================================

机身坐标约定：
  +X：机器人前方。
  +Y：机器人左方。
  +Z：机器人上方。

单腿平面运动学：
  髋轴为原点，使用 X-Z 平面，方向与机身上述定义一致。
  q1 是大腿相对机身的角度，不是独立于机身姿态的世界坐标角度。

髋角 q1 的定义：
- 零位：大腿沿机身参考坐标的 -Z 方向。
  机身水平摆正时，就是大腿竖直向下。
- 正方向：大腿向机器人前方摆动。
- 负方向：大腿向机器人后方摆动。

髋角暂定软件范围：
  -60° <= q1 <= +60°。
  弧度表示：-pi/3 <= q1 <= +pi/3。
  数值约为：-1.047197551 <= q1 <= +1.047197551 rad。

该范围后面可能修改，目前先保留。它不是已经验证的机械极限。
机身倾斜时，机身姿态与重力方向的关系由姿态和坐标变换另行处理。

============================================================
五、膝关节角 q2
============================================================

膝角含义：
  q2 是小腿相对大腿的有符号转角。
  它不是小腿相对地面的角度，也不是直接读取膝盖内夹角。

膝角零位：
  大腿、小腿同向伸直为 q2 = 0°。
  髋轴、膝轴、足端球心在同一条直线上，膝轴位于髋轴与足端球心之间。

  示例：q1=0°、q2=0°，机器人前方在右侧。

       髋轴 H ●                  +X 前方 ->
              |
              | 大腿
       膝轴 K ●
              |
              | 小腿
       足球心 ●

  小腿折回来贴近大腿，即使投影重合成一条线，也不属于这里的伸直零位。
  q2=0°不要求整条腿竖直；髋角可以不为零，而膝角仍保持零。

膝角正方向：
  从大腿的延长方向转向小腿，采用与 q1 相同的平面旋转方向。
  当大腿竖直向下时，小腿向前折为 q2>0，小腿向后折为 q2<0。
  当大腿倾斜时，q2仍相对大腿计算，不改成相对竖直线计算。

膝角最新暂定软件范围：
  -60° <= q2 <= +80°。
  弧度表示：-pi/3 <= q2 <= 4*pi/9。
  数值约为：-1.047197551 <= q2 <= +1.396263402 rad。

  之前讨论过的 ±45°、±60°范围已被这一范围替代。
  这个范围可在以后修改，尚未确认实际结构必定能达到两个端点。

膝角与膝盖内夹角的例子：
  q2=  0°：腿伸直，膝盖内夹角为180°。
  q2=+45°：向前折了45°，膝盖内夹角为135°。
  q2=-45°：向后折了45°，膝盖内夹角同样为135°。
  q2=+80°：向前折了80°，膝盖内夹角为100°。

“膝角45°”在本项目中不是“膝盖内夹角45°”。

============================================================
六、髋膝角组合关系与数学表达
============================================================

按照上面的统一旋转方向：
  大腿相对机身的角度：q1。
  小腿相对大腿的角度：q2。
  小腿相对机身的平面姿态角：q1 + q2。

例如：
  q1=30°、q2=0°：整条腿向前倾斜30°，膝关节保持伸直。
  q1=0°、q2=45°：大腿竖直，小腿相对大腿向前转45°。

由本坐标和角度约定推导出的串联正解：
  x = L1*sin(q1) + L2*sin(q1+q2)
  z = -L1*cos(q1) - L2*cos(q1+q2)

  x、z 表示足端球心相对髋轴的位置。
  代码中的三角函数输入为弧度，长度使用米。
  上述公式是后续迁移依据，不表示当前五连杆源码已经替换完成。

参考站立示例（仅为解释姿态，不是最终站立参数）：
  q1约为 -22.3567°，q2为 +45°。
  使用L1=250 mm、L2=247 mm时，足端球心位于髋轴正下方，距离约459.17 mm。
  这里的距离量到球心，不是量到地面，也不是机身上表面高度。

零位与站姿的区别：
- 数学上可以把伸直定义为膝角零位。
- 正常站立不要求膝角为零。
- 伸直时串联腿雅可比退化，速度逆解不能直接求逆；J转置乘力本身仍可计算。
- 最终正常站姿、站高、步长和蹲姿尚未确定，后续按工作空间重新选择。

============================================================
七、电机反馈角与关节角的区别
============================================================

theta1：髋电机减速器输出轴相对其外壳的角度。
theta2：膝电机减速器输出轴相对其外壳的角度。

有实物并标定后，使用：
  q1 = q1_ref + s1*(theta1-theta1_ref)
  q2 = q2_ref + s2*(theta2-theta2_ref)

其中：
- q_ref：参考姿态对应的关节角。
- theta_ref：该姿态下的电机输出轴反馈角。
- s1、s2：+1或-1，取决于真实安装和编码器增减方向。

必须区分：
- 关节向前为正，是已经确定的软件数学约定。
- 关节向前时电机反馈究竟增大还是减小，尚未实机确认。
- 数学零位不意味着电机反馈读数必须为零。
- 1:1同步带比与电机内部6.33减速比不是同一个传动环节。
- 当前8010驱动的位置、速度已有6.33换算，后续上层不能重复换算。

当前不要求实测的数据：
- 各关节theta_ref、s1/s2。
- 各台电机的实际串口、通信ID与髋膝位置对应。
- 实际机械极限、机身干涉和线缆允许范围。

这些数据以后有实物时再标定；目前不阻塞串联模型和电机接口的代码适配。
软件占位值必须注明未标定，不能当作真实安装参数或有效传感器反馈。
